# gns3_tutorials

Tutorials on using GNS3.

Read the guide at [GNS3 Tutorials](https://sagedemage.github.io/gns3_tutorials/).

## Commands

Install all dependencies
```
pnpm install
```

Start the website
```
pnpm dev
```

Build the website
```
pnpm build
```

Preview the built website
```
pnpm preview
```
